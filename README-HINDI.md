StayNest Multi-Owner Demo CRM

Start:
  npm install
  npm start

Super Admin demo credentials:
  ID: admin
  Password: admin123

Flow:
- Super Admin tab → create Hotel / PG owner account.
- Generated owner ID/password → Owner tab login.
- Owner creates properties, rooms, bookings and employee accounts.
- Generated employee ID/password → Employee tab login.
- Employee workspace is limited to Dashboard, Bookings and Rooms.

All data is stored in this browser's localStorage only. This is a demo, not production-secure authentication or tenant isolation. Do not use real customer data or reuse real passwords.
